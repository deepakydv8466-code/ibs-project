IBS Website Demo
================

How to run
1. Extract this folder.
2. Open index.html in Chrome/Edge.
3. Click Admin in the top navigation.

Demo admin credentials
Username: admin
Password: IBS@2026

Admin features
- Dashboard summary
- Add/edit/delete projects
- Add/edit/delete clients
- Add/edit/delete manpower/team records
- Add/edit/delete services
- Update contact details
- Capture website enquiries
- Export/import JSON backup
- Reset demo content

Storage note
This demo uses browser localStorage, so changes persist in that browser/device. For public production hosting with multiple admin users, replace localStorage with a secured database/API and server-side authentication.
